## Общее описание решения

В проекте созданы несколько файлов для работы с геометрическими фигурами и математические инструменты.

* `circle.py`  площадь и длина окружности круга
* `rectangle.py` площадь, периметр и диагональ прямоугольника
* `square.py` площадь и периметр квадрата
* `triangle.py` проверка существования треугольника, его площадь и периметр
* `mathutils.py` базовые мат. функции

Каждая функция принимает числовые аргументы и возвращает число или `bool` в случае проверок. Внешних зависимостей нет.

## Описание функций

### circle.py

`area(r)`

**Параметры:**

* `r` - `float`, радиус круга.

**Вывод:** **`area(r)`** (float) площадь круга радиуса `r`.

```
area(2) = 12.566...
```

`perimeter(r)`

**Параметры:**

* `r` - `float`, радиус окружности.

**Вывод:** **`perimeter(r)`** (float) длина окружности радиуса `r`.

```
perimeter(3) = 18.85...
```

### rectangle.py

`area(a, b)`

**Параметры:**

* `a` - `float`, первая сторона прямоугольника.
* `b` - `float`, вторая сторона прямоугольника.

**Вывод:** **`area(a, b)`** (float) площадь прямоугольника со сторонами `a` и `b`.

```
area(2, 4) = 8
```

`perimeter(a, b)`

**Параметры:**

* `a` - `float`, первая сторона прямоугольника.
* `b` - `float`, вторая сторона прямоугольника.

**Вывод:** **`perimeter(a, b)`** (float) периметр прямоугольника.

```
perimeter(2, 4) = 12
```

`diag(a, b)`

**Параметры:**

* `a` - `float`, первая сторона прямоугольника.
* `b` - `float`, вторая сторона прямоугольника.

**Вывод:** **`diag(a, b)`** (float) длина диагонали прямоугольника.

```
diag(3, 4) = 5.0
```

### square.py

`area(a)`

**Параметры:**

* `a` - `float`, сторона квадрата.

**Вывод:** **`area(a)`** (float) площадь квадрата со стороной `a`.

```
area(3) = 9
```

`perimeter(a)`

**Параметры:**

* `a` - `float`, сторона квадрата.

**Вывод:** **`perimeter(a)`** (float) периметр квадрата.

```
perimeter(3) = 12
```

### triangle.py

`is_triangle(a, b, c)`

**Параметры:**

* `a` - `float`, первая сторона треугольника.
* `b` - `float`, вторая сторона треугольника.
* `c` - `float`, третья сторона треугольника.

**Вывод:** **`is_triangle(a, b, c)`** (float) проверяет, существует ли треугольник с такими сторонами (неравенство треугольника).

```
is_triangle(3, 4, 5) = True
```

`area(a, b, c)`

**Параметры:**

* `a` - `float`, первая сторона треугольника.
* `b` - `float`, вторая сторона треугольника.
* `c` - `float`, третья сторона треугольника.

**Вывод:** **`area(a, b, c)`** (float) площадь треугольника по формуле Герона. Возвращает `0`, если треугольник не существует.

```
area(3, 4, 5) = 6.0
```

`perimiter(a, b, c)`

**Параметры:**

* `a` - `float`, первая сторона треугольника.
* `b` - `float`, вторая сторона треугольника.
* `c` - `float`, третья сторона треугольника.

**Вывод:** **`perimiter(a, b, c)`** (float) периметр треугольника.

```
perimiter(3, 4, 5) = 12
```

### mathutils.py

`gcd(a, b)`

**Параметры:**

* `a` - `int`, первое число.
* `b` - `int`, второе число.

**Вывод:** **`gcd(a, b)`** (int) наибольший общий делитель (алгоритм Евклида).

```
gcd(12, 18) = 6
```

`lcm(a, b)`

**Параметры:**

* `a` - `int`, первое число.
* `b` - `int`, второе число.

**Вывод:** **`lcm(a, b)`** (int) наименьшее общее кратное.

```
lcm(4, 6) = 12
```

`factorial(n)`

**Параметры:**

* `n` - `int`, число, для которого вычисляется факториал.

**Вывод:** **`factorial(n)`** (int) факториал числа `n`.

```
factorial(5) = 120
```

`is_prime(n)`

**Параметры:**

* `n` - `int`, проверяемое число.

**Вывод:** **`is_prime(n)`** (bool) проверка числа на простоту.

```
is_prime(7) = True
```
